# Credits: Queen Neve's boutique (shop builder)

Every model below was borrowed and restyled for Hoot Hollow: textures reduced to a single matte base colour
(normal, roughness and AO maps dropped), base colour downsized to 512 px or less, gently desaturated and tinted
towards the calm "Moss & Moonlight" palette, mesh welded and simplified towards a triangle budget, WebP + meshopt
compressed (`gltf-transform`, script kept in the builder's scratchpad: `pack.mjs`). Files live in
`public/models/shop/`. Upstream attributions are kept as the source projects list them.
